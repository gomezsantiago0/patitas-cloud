# Patitas Cloud

Agenda de citas para la veterinaria "Patitas". Proyecto de la materia PENU, Escuela Colombiana de Ingeniería Julio Garavito.

## Estructura

- `web/`: frontend estático
- `api/`: funciones de Azure (API)
- `infra/`: infraestructura como código (Bicep)
- `docs/`: HLD, diagramas, costos y evidencias
- `.github/workflows/`: pipelines de GitHub Actions

## Estado

Proyecto en construcción. Este README se completa al final con instrucciones de ejecución local, despliegue y arquitectura.
